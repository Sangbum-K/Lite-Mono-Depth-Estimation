# Research notes

논문 PDF 자체보다 출처 링크·인용 정보·자신의 이해를 기록한다. 제출 보고서에 들어갈 문장은 이 메모를 그대로 복사하지 않고 다시 작성한다.

읽기 순서:

1. Monodepth2: 자기지도 단안 깊이 학습의 기본 원리
2. Lite-Mono: baseline 구조와 효율성 기여
3. HR-Depth: decoder fusion과 경계 오류
4. RA-Depth: 해상도·scale consistency
5. Mono-ViFI: Lite-Mono를 사용한 후속 개선

새 논문을 읽을 때 `paper_note_template.md`를 복사해 `연도_짧은이름.md`로 저장한다. 논문에서 보고한 수치와 직접 재현한 수치를 반드시 구분한다.

논문 PDF를 개인적으로 내려받을 경우 `research/papers/`에 둘 수 있지만 Git에는 올리지 않는다. 공식 proceedings·arXiv·저자 코드 링크를 메모에 남긴다.
