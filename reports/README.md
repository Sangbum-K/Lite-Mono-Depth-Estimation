# Reports

세 보고서는 누적 구조다. 각 파일은 제출 전 학생이 자신의 이해와 문장으로 작성한다.

- `proposal.md`: 문제·데이터·관련연구·재현 계획
- `intermediate.md`: Proposal 요약 + baseline 재현 + 실패 분석 + 초기 개선
- `final.md`: 전체 이야기 + 모든 시도 + 최종 개선 + 한계
- `figures/`: 최종 보고서에서 실제 사용한 작은 그림

실험 숫자는 `experiments/` 기록과 일치하는지 확인하고, 그림에는 해당 run ID를 남긴다. 제출 PDF는 별도 생성 후 내용과 렌더링을 점검한다.
